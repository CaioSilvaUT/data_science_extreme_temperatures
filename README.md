# data_science_extreme_temperatures
Repositório para a matéria de Ciência de dados

## Instruções para rodar o projeto

Clone o repositório

```bash
git clone {link_do_repositorio}
```

Entre na pasta

```bash
cd data_science_extreme_temperatures
```


Rode o *uv sync*

```bash
uv sync
```
Conecte o kernel do vscode ao env do UV, clicando no botão *select kernel* no canto superior direito
